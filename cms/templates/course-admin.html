Управление курсами

Выберите курсы, проверьте новые номера запусков и создайте их с общими настройками. Здесь же можно изменить даты, видимость, режимы обучения и сертификаты существующих курсов.

Выбор отдельных курсов действует на текущей странице. «Все найденные курсы» охватывает все страницы применённых фильтров.

2. Задайте общие настройки

При сохранении существующих курсов пустые поля и «Без изменений» сохраняют текущие настройки. Для нового запуска обязательны начало и конец курса.

Расписание · ${timezone_label}

Введите время в UTC. Например, 09:00 по времени Алматы (UTC+5) = 04:00 UTC.

В новом запуске пустые даты записи и доступности сертификатов снимают прежние ограничения по датам.

Доступ и обучение

Включение генерации требует активного настроенного сертификата курса, а также включённых системных настроек HTML-сертификатов и генерации. Выбор режима Honor сам по себе не настраивает сертификат.

Видимость управляет каталогом и страницей описания курса. Она не закрывает учебные материалы для уже записанных студентов.

Расписание содержимого при перезапуске

Действует только при создании нового запуска. Календари внешних инструментов и задания ORA могут требовать отдельной проверки.

Новый ID сохраняет организацию и код курса. Год берётся из даты начала в UTC, а номер C выбирается следующим свободным: например, 2026_C1 → 2026_C2. Материалы копируются штатным перезапуском Studio. Если отключить перенос, даты разделов и заданий останутся прежними.

Сначала выберите курсы и проверьте новые ID. После изменения настроек проверку нужно повторить.

Изменить выбранные существующие курсы
Применяет заполненные поля к выбранным курсам. Новые запуски не создаются.

3. Результаты операций

Перезапуск выполняется в фоне. Состояние обновляется автоматически; после обновления страницы незавершённые операции появятся снова.
